# ScanReal — сканер реальности

Мобильное приложение: **камера + ИИ-распознавание объектов + датчики телефона** в реальном времени.
Работает полностью **на устройстве** — кадры никуда не отправляются, интернет нужен только
для первой загрузки модели.

---

## Что умеет

**Компьютерное зрение**
- Распознавание объектов через нейросеть **COCO-SSD** (80 классов: человек, машина, телефон,
  бутылка, чашка, ноутбук, кот, собака, стул, книга и другие)
- Рамки-видоискатели вокруг объектов с подписью и процентом уверенности
- Цвет рамки зависит от уверенности: голубой >70%, зелёный >55%, жёлтый >45%
- Плашки с найденными объектами под видео

**Датчики телефона**
- **Акселерометр** — наклон по трём осям + живой график в движении
- **Гироскоп** — углы поворота α/β/γ + живой график
- **Компас** — стрелка и азимут в градусах
- **Освещённость** — уровень света в люксах (логарифмическая шкала)

**Статистика**
- Всего объектов, классов найдено, время сессии, средняя уверенность
- Рейтинг распознанного с полосками частоты
- Защита от двойного счёта: один объект засчитывается раз в 2,5 секунды

**Как приложение**
- PWA: ставится иконкой на домашний экран, работает офлайн
- Тёмный «приборный» интерфейс, рассчитан на телефон
- Экономия батареи: распознавание ~8 раз в секунду, камера глушится в фоне

## Быстрый запуск (демо)

### Вариант 1 — локальный сервер

```powershell
cd "C:\Users\Stanislav\Desktop\DEEPSEEK проекты\ScanReal"
npm run dev
```

Откроется `http://localhost:5178`. На компьютере камера и датчики работать не будут —
это нормально, там их нет.

### Вариант 2 — показать на телефоне (нужен HTTPS)

**Камера в браузере работает только по HTTPS.** По локальному IP (`http://192.168.x.x`)
браузер её заблокирует. Поэтому нужен туннель:

```powershell
# Терминал 1 — собираем и запускаем приложение
npm run build
npx vite preview --host --port 5178

# Терминал 2 — поднимаем HTTPS-туннель
.\tools\cloudflared.exe tunnel --url http://127.0.0.1:5178 --no-autoupdate
```

В логе второго терминала появится ссылка вида:

```
https://что-то-там.trycloudflare.com
```

Откройте её на телефоне → разрешите камеру → приложение заработает.
Ссылка живёт, пока запущены оба терминала.

> **Совет для демо:** на телефоне откройте меню браузера → «Установить приложение»
> (или «Добавить на главный экран»). Появится иконка ScanReal, приложение откроется
> на весь экран без адресной строки — выглядит как обычное Android-приложение.

## Сборка APK (настоящее приложение)

Локально Android SDK не установлен, поэтому APK собирается **в облаке GitHub** —
устанавливать ничего не нужно.

1. Создайте репозиторий на GitHub и загрузите туда папку `ScanReal`:

```powershell
cd "C:\Users\Stanislav\Desktop\DEEPSEEK проекты\ScanReal"
git init
git add .
git commit -m "ScanReal"
git branch -M main
git remote add origin https://github.com/ВАШ_ЛОГИН/ScanReal.git
git push -u origin main
```

2. Откройте репозиторий на GitHub → вкладка **Actions**.
   Сборка запустится сама (~5–8 минут).

3. Когда сборка закончится → откройте её → внизу раздел **Artifacts** →
   скачайте **ScanReal-debug-apk** (внутри `.apk`).

4. Перекиньте APK на телефон и установите (разрешите «Установка из неизвестных источников»).

Готовый workflow лежит в `.github/workflows/build-apk.yml` — он сам собирает веб-часть,
добавляет Android-платформу Capacitor, прописывает разрешение на камеру и собирает APK.

## Структура проекта

```
ScanReal/
├─ index.html                    разметка: экран загрузки, камера, статистика
├─ package.json                  зависимости и команды
├─ vite.config.js                сборка (разрешены внешние хосты для туннеля)
├─ capacitor.config.json         настройки упаковки в Android
├─ src/
│  ├─ main.js                    логика: камера, цикл распознавания, статистика
│  ├─ detector.js                нейросеть COCO-SSD + русские названия классов
│  ├─ sensors.js                 акселерометр, гироскоп, компас, свет
│  ├─ visual.js                  отрисовка живых графиков датчиков
│  └─ styles.css                 оформление интерфейса
├─ public/
│  ├─ manifest.webmanifest       описание PWA (имя, иконки, цвета)
│  ├─ sw.js                      service worker: офлайн-работа
│  └─ icons/                     иконки приложения
├─ scripts/
│  ├─ generate-icons.mjs         генерация иконок без внешних библиотек
│  └─ patch-manifest.mjs         прописывает разрешения в AndroidManifest
├─ .github/workflows/build-apk.yml   облачная сборка APK
└─ tools/cloudflared.exe         туннель для HTTPS (нужен для камеры на телефоне)
```

## Честные ограничения

- **80 классов, а не «всё подряд».** COCO-SSD знает человека, машину, кота, бутылку, чашку,
  телефон, ноутбук, книгу и ещё ~70 категорий. Экзотический предмет она не назовёт.
  Для демо это не проблема, но не стоит обещать «распознаёт что угодно».
- **Датчики зависят от телефона.** Акселерометр и гироскоп есть везде, компас — почти везде,
  датчик освещённости — в основном на Android. Если датчика нет, поле покажет «—».
- **Датчики движения по HTTPS** в некоторых браузерах требуют явного разрешения —
  приложение запрашивает его само при включении камеры.
- **Первый запуск требует интернета** — скачиваются веса модели (~5 МБ).
  Дальше service worker отдаёт их из кэша, приложение работает офлайн.
- **Это debug-APK**, не для публикации в Play Market. Для публикации нужна релизная
  подпись (keystore) — это отдельный шаг, делается человеком.
